# ระบบสำรวจการใช้ชุดกิจกรรมการเรียนรู้ (ใบงาน) DLTV

เว็บแบบสำรวจ 3 กลุ่มเป้าหมาย (ผู้บริหาร / ครู / นักเรียน) ตามแบบฟอร์ม PDF ทั้ง 3 ชุด
ผู้ตอบค้นหาชื่อโรงเรียนแล้วระบบดึงข้อมูลพื้นฐานมาให้ พร้อมแยกกลุ่มการจัดสรรใบงาน
(ภาคเรียนที่ 1 / ภาคเรียนที่ 2 / ทั้ง 2 ภาคเรียน / โรงเรียนต้นทาง) เก็บข้อมูลใน Firebase Firestore
และมีหน้าหลังบ้านสำหรับดูผลวิเคราะห์และดาวน์โหลด Excel

## โครงสร้างไฟล์

```
public/
  index.html          หน้าแบบสำรวจ (ผู้ตอบทุกกลุ่ม)
  admin.html          หน้าหลังบ้าน (ต้องล็อกอิน)
  css/style.css
  js/config.js        ★ ตั้งค่า Firebase และปีการศึกษา
  js/questions.js     ข้อคำถามทั้งหมด (แก้ข้อความคำถามได้ที่นี่)
  js/store.js         เชื่อมต่อ Firestore / Auth
  js/survey.js        ตรรกะหน้าแบบสำรวจ
  js/admin.js         ตรรกะหน้าหลังบ้าน
  data/schools.json   รายชื่อโรงเรียน 9,140 แห่ง (สร้างจากไฟล์ Excel)
tools/build_schools.py  แปลง Excel -> schools.json
firestore.rules       กฎความปลอดภัยของฐานข้อมูล
firebase.json         ตั้งค่า Firebase Hosting
```

ถ้ายังไม่ได้ใส่ค่า Firebase ระบบจะทำงานใน **โหมดสาธิต** (เก็บข้อมูลในเบราว์เซอร์) เปิดลองได้ทันทีด้วย
`cd public && python3 -m http.server 8000` แล้วเข้า http://localhost:8000

## ติดตั้งบน Firebase (ครั้งแรก)

1. เข้า https://console.firebase.google.com สร้างโปรเจกต์ใหม่
2. **Firestore Database** → Create database → Production mode → เลือก location `asia-southeast1` (สิงคโปร์)
3. **Authentication** → Get started → เปิด **Email/Password**
4. **Project settings** → Your apps → เพิ่ม Web app (`</>`) → คัดลอกค่า `firebaseConfig`
   มาวางใน `public/js/config.js` ส่วน `FIREBASE_CONFIG`
5. ติดตั้งเครื่องมือและ deploy (ต้องมี Node.js)
   ```bash
   npm install -g firebase-tools
   firebase login
   cp .firebaserc.example .firebaserc     # แก้ YOUR-FIREBASE-PROJECT-ID เป็น Project ID จริง
   firebase deploy                         # อัปโหลดทั้งหน้าเว็บ (Hosting) และกฎ Firestore
   ```
   จะได้ลิงก์ `https://<project-id>.web.app` สำหรับส่งให้โรงเรียน

## เพิ่มผู้ดูแลระบบ (เข้าหน้าหลังบ้าน)

1. **Authentication** → Users → Add user → ใส่อีเมลและรหัสผ่าน
2. **Firestore** → Start collection ชื่อ `admins` → Document ID = อีเมลเดียวกัน **ตัวพิมพ์เล็กทั้งหมด**
   (เช่น `adipong@dltv.ac.th`) ใส่ field อะไรก็ได้ เช่น `name: "ชื่อผู้ดูแล"`
3. เข้า `https://<project-id>.web.app/admin.html` แล้วล็อกอิน

ผู้ที่มีบัญชีแต่ไม่มีเอกสารใน `admins` จะอ่านข้อมูลไม่ได้

## อัปเดตรายชื่อโรงเรียน

แก้ไฟล์ Excel (หัวตาราง: ที่ | รหัส | โรงเรียน | ตำบล | อำเภอ | จังหวัด | รหัสไปรษณีย์ | เบอร์โทรศัพท์ | เขตพื้นที่การศึกษา | การจัดสรร)
แล้วรัน

```bash
pip install openpyxl
python3 tools/build_schools.py "ไฟล์ข้อมูลรร.ที่ได้รับใบงาน.xlsx"
firebase deploy --only hosting
```

กลุ่มการจัดสรรอ่านจากคอลัมน์ "การจัดสรร" (ข้อความที่มี "ภาคเรียนที่ 1", "ภาคเรียนที่ 2", "ทั้ง 2 ภาคเรียน")

## เริ่มรอบสำรวจปีใหม่ / ปิดรับคำตอบ

แก้ `public/js/config.js`: `year` (ทุกคำตอบบันทึกปีไว้), `open: false` เพื่อปิดรับ แล้ว `firebase deploy --only hosting`

## กติกาที่ระบบบังคับ

- **ผู้บริหารตอบได้ 1 ชุดต่อโรงเรียน** (รหัสเอกสาร = `director_<รหัสโรงเรียน>` กฎ Firestore ห้ามเขียนทับ)
  ถ้าโรงเรียนต้องการแก้คำตอบ ผู้ดูแลลบคำตอบเดิมที่แท็บ "รายการคำตอบ" แล้วให้โรงเรียนส่งใหม่
- ครูและนักเรียนตอบได้คนละ 1 ชุด (ระบบไม่บังคับซ้ำ เพราะไม่มีการเก็บชื่อ)
- ส่งแล้วแก้ไขไม่ได้ ผู้ตอบทั่วไปอ่านข้อมูลของคนอื่นไม่ได้
- แบบฟอร์มที่กรอกค้างไว้ถูกบันทึกในเครื่องผู้ตอบ กลับมาทำต่อได้

## โครงสร้างข้อมูลใน Firestore (collection `responses`)

| field | ความหมาย |
|---|---|
| role | `director` / `teacher` / `student` |
| allocation | `sem1` / `sem2` / `both` / `origin` |
| schoolType | `destination` (ปลายทาง) / `origin` (ต้นทาง/นอกรายชื่อ) |
| affiliation | `obec` สพฐ. / `bpp` ตชด. / `wkk` วังไกลกังวล |
| schoolCode, schoolName, tambon, amphoe, province, zip, phone, area | ข้อมูลโรงเรียน |
| surveyYear, submittedAt | ปีการศึกษา, เวลาส่ง (เวลาเซิร์ฟเวอร์) |
| answers | คำตอบตามแบบฟอร์ม เช่น `answers.ratings.thai_1` = คะแนน 20 ข้อของครูวิชาภาษาไทย ป.1, `answers.ratings.eng` = คะแนน 12 ข้อของนักเรียนวิชาภาษาอังกฤษ |

## หน้าหลังบ้าน

- กรองตามกลุ่มการจัดสรร จังหวัด เขตพื้นที่ ประเภทโรงเรียน
- ภาพรวม: อัตราการตอบแต่ละกลุ่มการจัดสรร ค่าเฉลี่ยรายวิชา แยกจังหวัด
- ครู / นักเรียน: ค่าเฉลี่ย (x̄) S.D. และระดับ รายข้อ รายด้าน เลือกวิชา/ชั้นได้
- ผู้บริหาร: ลักษณะการใช้ ตารางวิชา×ชั้น ครูวิชาเอก รายชื่อผู้ประสานงาน DLTV
- ข้อเสนอแนะ: ค้นหาข้อความ
- ดาวน์โหลด Excel: ข้อมูลดิบทุกกลุ่ม คะแนนรายข้อ และตารางสรุป + รายชื่อโรงเรียนที่ผู้บริหารยังไม่ตอบ (ใช้ติดตาม)

## ข้อควรรู้เรื่องค่าใช้จ่าย

แผนฟรี (Spark) ของ Firestore อ่านได้ 50,000 เอกสาร/วัน เขียนได้ 20,000/วัน
หน้าหลังบ้านโหลดคำตอบทั้งหมดทุกครั้งที่เปิดหรือกด "โหลดข้อมูลใหม่" ถ้าคำตอบมีหลายหมื่นรายการ
และเปิดดูบ่อย ควรเปลี่ยนเป็นแผน Blaze (จ่ายตามใช้ ราคาต่ำมากสำหรับปริมาณนี้)
แนะนำเปิด **App Check** (reCAPTCHA) เพื่อป้องกันการส่งข้อมูลขยะจากบอต
